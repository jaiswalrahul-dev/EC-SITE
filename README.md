# EC-SITE
# PHP ECサイト

## 概要
PHPを使用して制作したECサイトです。
商品の一覧表示、商品詳細、カート機能など、基本的なECサイトの機能を実装しています。

## 使用技術
- PHP
- HTML
- CSS
- JSON

## 主な機能
- 商品一覧表示
- 商品詳細ページ
- カートへの追加・削除
- 合計金額の計算
- レスポンシブデザイン

## 工夫した点
- 見やすく使いやすい画面デザインを意識しました。
- コードを整理し、再利用しやすい構成にしました。
